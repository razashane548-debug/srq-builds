## Current public release

- Version 0.3.5, version code 8. Public pre-release, not a final release.
- Android 6.0 or later. Direct APK download, not a Google Play listing.
- File size: 77,076,890 bytes (73.5 MiB).
- No ads or in-app purchases in this public version.
- App text: English, Hindi, Urdu and Indian Punjabi.

## Reading tools

- Read document text aloud with compatible speech voices installed on your phone.
- Use on-device OCR for scanned pages.
- Save notes and use chapter navigation and reading tools.
- Translate between English, Hindi and Urdu after downloading models with consent. Punjabi translation is not supported.
- Back up encrypted library/bookmark metadata. Original book files and audio are not included.

## Known limits

OCR, translation and reading order can be wrong. Not every scanned PDF can be read aloud. Speech and file-picker behavior depend on your phone. Audio export may fail on low-storage phones. Device regression checks for the September 30 security replacement remain pending. No all-device compatibility or security certification is claimed.

Keep Google Play Protect on and scan the APK before installing. If it identifies the app as harmful, stop rather than bypassing the warning.
